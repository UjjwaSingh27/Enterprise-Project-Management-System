# Enterprise Project Management System

An enterprise-grade web application developed to simplify project planning, task tracking, timeline management, and document organization.

This project was developed during my internship at Tata Steel, where I gained practical experience in enterprise software development and database-driven web applications.

---

## Features

- Interactive Gantt Chart
- Project Groups & Categories
- Project and Phase Management
- Task Hierarchy & Dependencies
- Planned vs Actual Timeline Tracking
- Progress Monitoring
- Role-Based Access Control
- Dashboard Analytics
- Project Document Management
- Task Attachments
- Excel Import & Export
- Responsive Modern UI
